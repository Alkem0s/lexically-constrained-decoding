Readme for NLP Authoring Template
=================================

The first release CUP-JNL-NLP.cls (version 1.1) and LaTeX template includes the following files:
(The current release is version 1.1)

********************************** Files ***************************************************************

README.txt               - This file.

CUP-JNL-NLP.cls          - The CUP NLP authoring class file.

NLP_guide.pdf            - The user manual and sample output for how to work with author templates.

NLP_guide.tex            - The sample TeX file of LaTeX template.

NLP-BR-Sample.pdf        - Book Review sample output PDF.

NLP-BR-Sample.tex        - Book Review sample input TeX.

NLPlike.bst              - A similar NLP bibliography style file to generate bibliography from bib file.

cup_logo.eps 		 - Journal logo.

Sample.bib 	         - Sample Bib file format

**********************************************************************************************************

* Please install sourcesanspro package if it is not available from https://tug.org/FontCatalogue/sourcesanspro/.
